# Búfer de fricción

Anota clases de fricción que requieren más evidencia antes de proponer una
regla. Cada instancia incluye fecha, origen y evidencia verificable.

- **Umbral de promoción**: tres instancias o dos proyectos o sesiones distintos.
- **Criterio de muerte**: si ninguna clase se promueve en diez sesiones de
  revisión, evalúa retirar el búfer del proyecto.
- **Slugs en uso**: registra aquí los identificadores a medida que aparecen y
  reutilízalos para agrupar instancias.
