# Evolución del framework

El framework reúne una plantilla de proyecto, flujos de desarrollo guiado por
especificaciones, un motor de estado local y adaptadores para distintos agentes.
Las especificaciones formales viven en el proyecto y se pueden cargar por etapa.

Consulta el [registro de cambios](CHANGELOG.md) y las
[decisiones de arquitectura](framework_arch_decisions.md).
