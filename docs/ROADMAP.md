# Hoja de ruta

La primera edición incluye la plantilla, el motor de estado local y un
ejemplo de continuidad que cualquiera puede ejecutar sin una cuenta de IA.
El [historial de cambios](../.agent/docs/CHANGELOG.md) recoge lo que ya llegó a
cada versión.

## Próximos temas de mantenimiento

| Prioridad | Trabajo | Evidencia de cierre |
| --- | --- | --- |
| Instalación | Probar la guía con una persona que configure por primera vez un proyecto. | Pasos reproducibles y corrección de las dudas que aparezcan. |
| Claude Code y Codex | Probar arranque, continuidad y verificación en sesiones reales. | Entorno, versión y resultado por integración. |
| Contribuciones | Priorizar problemas de instalación y regresiones que puedan reproducirse. | Issue con pasos, cambio asociado y prueba del arreglo. |

El estado de cada trabajo se registra en su issue cuando se abre. Los cambios se
enlazan desde la pull request y se resumen en el historial al publicarse.
Las prioridades pueden cambiar según los reportes de uso.
